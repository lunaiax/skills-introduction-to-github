# Сайт компании (статический HTML/CSS/JS)

Готовая заготовка многостраничного бизнес‑сайта для размещения на хостинге **Infomaniak**.

## Структура

```
website/
├── index.html        # Главная
├── about.html        # О нас
├── services.html     # Услуги
├── contact.html      # Контакты + форма
├── css/
│   └── style.css     # Все стили (цвета меняются вверху файла в :root)
├── js/
│   └── main.js       # Мобильное меню, год в подвале, форма
└── images/           # Сюда положите логотип и картинки
```

## Как посмотреть локально

Просто откройте файл `index.html` двойным щелчком в браузере — сайт полностью рабочий, без сборки и без сервера.

## Как поменять содержимое

- **Тексты** — прямо в `.html` файлах, замените слова‑заглушки на свои.
- **Цвета и шрифт** — вверху `css/style.css`, блок `:root` (переменные `--color-primary`, `--color-accent` и т.д.).
- **Логотип** — в шапке сейчас текст `Ваша​Компания`. Чтобы поставить картинку, замените
  `<a href="index.html" class="logo">…</a>` на `<a href="index.html" class="logo"><img src="images/logo.png" alt="Логотип" style="height:40px"></a>`.
- **Контакты** — телефон, email, адрес в `contact.html` и в подвале каждой страницы.

## 🚀 Размещение на Infomaniak

У вас уже есть хостинг и домен на Infomaniak, поэтому нужно просто загрузить файлы из папки `website/` в корень сайта.

### Вариант 1. Через веб‑интерфейс Infomaniak (проще всего)

1. Войдите в **Infomaniak Manager** → https://manager.infomaniak.com
2. Откройте **Hébergement Web / Веб‑хостинг** → выберите ваш хостинг.
3. Найдите **Менеджер файлов (File Manager)**.
4. Перейдите в папку сайта — обычно это `sites/имя-домена/` или `web/`
   (папка, которую Infomaniak показывает как «racine du site» / корень сайта).
5. Загрузите **содержимое папки `website/`** (все файлы и папки `css`, `js`, `images`),
   а не саму папку `website`. То есть `index.html` должен оказаться в корне сайта.

### Вариант 2. Через FTP (FileZilla)

1. В Manager создайте FTP‑аккаунт: **Веб‑хостинг → FTP/SSH → добавить пользователя**.
2. Скачайте [FileZilla](https://filezilla-project.org/) и подключитесь:
   - **Хост:** обычно `ftp.ваш-домен.ch` или адрес из панели Infomaniak
   - **Имя пользователя** и **пароль:** из FTP‑аккаунта
   - **Порт:** 21 (FTP) или 22 (SFTP)
3. Слева (локально) откройте папку `website/`, справа — корневую папку сайта.
4. Перетащите **все файлы из `website/`** в корень сайта.

### Вариант 3. Автопубликация из GitHub (по желанию)

Infomaniak умеет разворачивать сайт напрямую из Git‑репозитория:
**Веб‑хостинг → выбрать сайт → Déploiement Git / Развёртывание из Git**.
Укажите репозиторий и ветку — при каждом пуше сайт обновляется автоматически.
⚠️ Учтите: корнем публикации нужно указать папку `website/`.

### Проверка

После загрузки откройте `https://ваш-домен` — должна показаться главная страница.
Если открывается список файлов, убедитесь, что `index.html` лежит в корне сайта.

## ✉️ Чтобы форма обратной связи реально отправляла письма

Сейчас форма на странице «Контакты» — заглушка (показывает сообщение, но письмо не отправляет),
потому что статический сайт не может сам отправлять почту.

Варианты подключить отправку:

1. **Почта Infomaniak + PHP.** Infomaniak поддерживает PHP. Можно добавить небольшой
   файл `send.php`, который отправляет письмо через `mail()` на ваш ящик Infomaniak.
   Напишите мне — добавлю готовый обработчик.
2. **Внешний сервис форм** (без кода): например Formspree, Web3Forms — достаточно
   вставить их адрес в атрибут `action` формы.

Подскажите, какой вариант удобнее, — настрою.
