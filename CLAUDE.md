# Claude Agents Configuration

Этот проект использует набор специализированных агентов Claude Code для
автоматизации контент-маркетинга и работы с данными. Определения агентов
находятся в каталоге [`.claude/agents/`](.claude/agents/) — каждый агент
описан отдельным файлом с YAML-заголовком (`name`, `description`, `tools`,
`model`) и системным промптом.

Claude автоматически выбирает подходящего агента на основе твоего запроса.

## Доступные агенты

| Агент | Файл | Назначение |
| --- | --- | --- |
| `social-media-writer` | [`.claude/agents/social-media-writer.md`](.claude/agents/social-media-writer.md) | Посты для Instagram, TikTok, LinkedIn, хэштеги, карусели |
| `content-analyzer` | [`.claude/agents/content-analyzer.md`](.claude/agents/content-analyzer.md) | Анализ вовлеченности постов, рекомендации |
| `product-writer` | [`.claude/agents/product-writer.md`](.claude/agents/product-writer.md) | Описания товаров, спецификации, преимущества |
| `data-processor` | [`.claude/agents/data-processor.md`](.claude/agents/data-processor.md) | Очистка и форматирование данных (CSV, JSON) |
| `email-writer` | [`.claude/agents/email-writer.md`](.claude/agents/email-writer.md) | Профессиональные письма, рассылки, сообщения клиентам |
| `trend-researcher` | [`.claude/agents/trend-researcher.md`](.claude/agents/trend-researcher.md) | Исследование трендов, конкурентов, рынка |
| `content-planner` | [`.claude/agents/content-planner.md`](.claude/agents/content-planner.md) | Календарь контента, график постов, планирование |

---

## 🚀 Как использовать эти агенты?

**Просто напиши задачу:**

```
"Создай 3 поста для Instagram про чай Gold Ceylon"
→ social-media-writer автоматически создаст посты

"Анализируй наши последние 20 постов и скажи какие работают лучше"
→ content-analyzer разберёт данные и выдаст отчёт

"Очисти файл customers.csv от дубликатов"
→ data-processor уберёт мусор и вернёт чистые данные

"Напиши письмо новым клиентам про скидку 15%"
→ email-writer создаст профессиональное письмо
```

---

## ⚙️ Как это работает?

1. **Держи этот файл** как `CLAUDE.md` в корневой папке проекта, а агентов — в `.claude/agents/`
2. **Открой Claude Code** на своём компьютере
3. **Просто описывай задачу** — Claude автоматически выберет нужного агента
4. **Агент выполнит работу** и сохранит результат

## 💡 Советы

- **Будь конкретен**: "Создай пост про чай для Instagram молодежи 18-25" лучше чем просто "Создай пост"
- **Показывай примеры**: Если нужен определенный стиль, показывай примеры постов
- **Итерируй**: Если первый вариант не понравился, попроси улучшить
- **Комбинируй**: Можешь использовать вывод одного агента как вход для другого
